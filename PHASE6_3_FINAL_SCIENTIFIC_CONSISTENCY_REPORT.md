## 4. Flood Area Calculation Methodology & Terminology

The 14,369 flood pixels identified in the $256 \times 256$ raster (`pipeline_exec_8f7ef10bcb32_flood_mask.tif`) have been evaluated across four rigorous methodologies:

| Area Metric Name | Mathematical Formulation | Area ($\text{km}^2$) | Area (Hectares) | Context & Terminology |
| :--- | :--- | :---: | :---: | :--- |
| **Planar Approximation (Codebase)** | $14,369 \times (0.000390625^\circ \times 111,320) \times (0.000312500^\circ \times 110,540)$ | **$21.584\text{ km}^2$** | **$2,158.39\text{ ha}$** | Planar Euclidean formula in `floodsense_pipeline.py`. Omits latitude cosine convergence. |
| **Centroid-Based Geodesic Estimate** | $14,369 \times \text{GeodWGS84}(\text{lon}_{\text{cen}}, \text{lat}_{\text{cen}}, \Delta\text{lon}, \Delta\text{lat})$ | **$21.050\text{ km}^2$** | **$2,104.97\text{ ha}$** | Evaluates a single geodesic cell at scene centroid ($13.020^\circ\text{N}, 80.240^\circ\text{E}$). |
| **Exact Row-Integrated Geodesic Area** | $\sum_{r=0}^{255} N_{\text{flood}, r} \times \text{GeodWGS84}(\text{lon}_{\text{cen}}, \text{lat}_r, \Delta\text{lon}, \Delta\text{lat})$ | **$21.049\text{ km}^2$** | **$2,104.93\text{ ha}$** | Exact row-by-row geodesic integration across the 256 latitudinal rows. |
| **Reprojected UTM 44N Metric Area** | Reprojection to UTM Zone 44N (`EPSG:32644`) equal-area metric cells | **$21.025\text{ km}^2$** | **$2,102.46\text{ ha}$** | Transverse Mercator conformal metric grid calculation. |
| **Phase 5 Urban Core Sub-Sector** | Evaluated on compact urban bounding box ($[13.01, 80.22, 13.06, 80.27]$) | **$6.578\text{ km}^2$** | **$657.80\text{ ha}$** | Localized urban sub-sector only. |

### 4.1 Key Mathematical Deductions
1. **Centroid vs. Row-Integrated Delta:** The delta between the **Centroid-Based Geodesic Estimate** ($21.050\text{ km}^2$) and the **Exact Row-Integrated Geodesic Area** ($21.049\text{ km}^2$) is only **$0.00043\text{ km}^2$ ($0.043\text{ ha}$, $0.0021\%$)**. This confirms that treating the centroid pixel as representative introduces negligible error over an $0.08^\circ$ latitudinal span.
2. **Planar Formula Overestimation:** The planar formula overestimates true geodesic area by $+2.47\%$ because it does not scale longitude by the parallel convergence factor:
   $$\cos(13.02^\circ) \approx 0.9743$$
   Both the planar value ($21.584\text{ km}^2$) and the geodesic value ($21.050\text{ km}^2$) are preserved and explicitly distinguished.

## 5. Infrastructure Metric Reconciliation (Phase 5 vs. Phase 6.1)

### 5.1 The Numerical Shift
- **Phase 5:** 229 High Exposure Buildings, 10 Moderate, 761 Low, 0 Unknown | 195 Road Hazards, 25 Caution, 771 Clear, 9 Unknown.
- **Phase 6.1:** 290 High Exposure Buildings, 4 Moderate, 706 Low, 0 Unknown | 504 Road Hazards, 27 Caution, 469 Clear, 0 Unknown.

### 5.2 Empirical Forensic Verification
Through programmatic tests comparing the files and algorithms, five facts are proven:

1. **OSM Vector Cache Checksums are Identical:**
   - `backend/data/osm_cache/chennai_buildings.geojson`: MD5 `6f54cb40e23f183cff3191f7de4ee197` (27,884 polygons, identical in both phases).
   - `backend/data/osm_cache/chennai_roads.geojson`: MD5 `6877e1f498d2a150c64fb8829e867540` (5,272 ways, identical in both phases).
2. **Underlying $256 \times 256$ Classification Masks are Bit-Exact Identical:**
   - Comparing `flood_mask_024d3597.tif` (Phase 5) and `pipeline_exec_8f7ef10bcb32_flood_mask.tif` (Phase 6.1):
     ```python
     np.array_equal(mask_p5, mask_p6) == True
     ```
   - Both rasters have: 32,202 dry land, 18,965 permanent water, 14,369 floodwater.
3. **Sampling Strategies are Identical:**
   - Buildings: Deterministic stride decimation: `step = 27884 // 1000 = 27`, taking `buildings[::27][:1000]`. The identical 1,000 buildings were analyzed in both phases.
   - Roads: First 1,000 features sequentially: `roads[:1000]`. The identical 1,000 roads were analyzed in both phases.
4. **Classification Thresholds are Identical:**
   - Building exposure tiers: High $\ge 50\%$, Moderate $10\text{--}50\%$, Low $< 10\%$.
   - Road hazard tiers: Potential Hazard $\ge 30\%$, Caution $5\text{--}30\%$, Clear $< 5\%$.
5. **The Sole Cause of Metric Shift: The Georeferencing Transform:**
   - Phase 5 Bounding Box: $[13.010^\circ\text{N}, 80.220^\circ\text{E}, 13.060^\circ\text{N}, 80.270^\circ\text{E}]$ ($0.05^\circ \times 0.05^\circ$, resolution $0.0001953^\circ$/pixel).
   - Phase 6.1 Bounding Box: $[12.980^\circ\text{N}, 80.190^\circ\text{E}, 13.060^\circ\text{N}, 80.290^\circ\text{E}]$ ($0.08^\circ \times 0.10^\circ$, resolution $0.0003125^\circ \times 0.0003906^\circ$/pixel).
   - Because the affine transform converts geographic coordinates $(lon, lat)$ to raster row and column indices:
     $$\text{col} = \frac{\text{lon} - \text{min\_lon}}{\text{res\_x}},\quad \text{row} = \frac{\text{max\_lat} - \text{lat}}{\text{res\_y}}$$
     The same building at $(80.23^\circ\text{E}, 13.03^\circ\text{N})$ maps to $(\text{row } 153.6, \text{col } 51.2)$ in Phase 5, but to $(\text{row } 96.0, \text{col } 102.4)$ in Phase 6.1.
   - Running the exact Phase 5 code under `georef_p5` replicates: **229 High, 10 Moderate, 761 Low / 195 Hazard, 25 Caution, 771 Clear**.
   - Running the exact Phase 6.1 code under `georef_p6` replicates: **290 High, 4 Moderate, 706 Low / 504 Hazard, 27 Caution, 469 Clear**.

This confirms that the variation is purely mathematical and geospatial, caused by expanding the spatial frame of reference.
